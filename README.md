# Content APP - Sanity Studio

This is a pet project for learning Sanity.io, with a focus on data migrations, GitHub workflows, and automatic deployment to Vercel. The deployed studio is available at https://app-sanity-content.vercel.app/. It has been customized with the following features:

## Project Purpose

This project was created as a pet project to learn Sanity.io, with a focus on schema customization and data migrations.

## Custom Schema Types

*   **Page:** For creating general pages on the website.
*   **Portfolio:** For showcasing projects in the portfolio. Each portfolio item includes details like title, description, project URL, images, and associated skills.
*   **Skill:** For managing the list of skills that can be associated with portfolio projects.

## Custom Desk Structure

The studio's desk structure has been customized to provide a more organized view of the content, with separate sections for different content types.
